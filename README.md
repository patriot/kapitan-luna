# Капитан на Луне-Крохе

Браузерная игра-платформер для ребёнка 6 лет. Настоящие дела дома («почистил зубы», «убрал игрушки», поручения родителей) заряжают скафандр капитана. Заряд нужен в игре: для реактивного ранца, дополнительных уровней, улучшений и перелётов на новые планеты.

Игра работает в браузере телефона, без установки. Управление — большие кнопки на экране. Лучше держать телефон горизонтально.

## Что внутри

- **3 планеты, 11 уровней**: Луна-Кроха, Мармеладия, Кристаллон.
- **Миссия на каждом уровне**:
  - сложить слово из букв;
  - найти предметы с нужным звуком (фонематический слух);
  - собрать ровно 7 кристаллов;
  - разложить вещи по местам;
  - запомнить код;
  - починить робота по устной инструкции;
  - накормить зайчат нужным числом морковок;
  - разложить утро или вечер по порядку;
  - понять чувства друзей и помочь им;
  - освободить и привести домой зайчат.
- **Препятствия, на которых нужно подумать**:
  - числовые мосты;
  - загадочные ворота: первая буква, «где больше», узор, кристаллы по размеру;
  - говорящая дверь и пещера-эхо (логопедия);
  - лазер-светофор: научиться ждать;
  - спящий дракончик: пройти тихо;
  - дыхательное упражнение с вулканом;
  - фонарики по порядку от 1 до 5;
  - пары карточек;
  - скользкий лёд, батуты, лифты, летающие платформы.
- **Сундук «Миссия из жизни»**: задание, которое ребёнок выполняет дома, а родитель подтверждает.

## Для родителей

- **ЦУП (центр управления полётами).** Кнопка «ЦУП» на базе. Вход через пример на умножение, который шестилетний ребёнок не решит. Там настраиваются:
  - имя капитана;
  - звук для логопедических заданий и этап (слоги, слова, фразы);
  - лимит игры в день (10–30 минут);
  - радиограммы с поручениями;
  - задание для «Миссии из жизни».

  Там же бортовой журнал дня.
- **Баланс.** Каждый день один уровень бесплатно, каждый следующий стоит 2 ⚡. Подтверждённое дело даёт +1 ⚡, радиограмма +2 ⚡.
- **Мягкие правила.** Жизней нет, уровни проходятся без улучшений. Если выйти из уровня в первые 30 секунд, он не засчитывается.
- **Логопедия.** Звук и этап выбирайте вместе с логопедом. Берите только звук, который уже поставлен.
- **Прогресс** хранится в браузере того телефона, на котором играют. На сервер ничего не отправляется.
- **Голос** — встроенный синтезатор речи телефона. Нужен русский голос в системе.

## Файлы

- `index.html` — сама игра, всё в одном файле.
- `iskra.html` — первый прототип «Капитан Звёздного Патруля» (дела, приказы на слух, графический диктант, артикуляционная разминка).

Чтобы запустить на компьютере, откройте `index.html` в браузере. Чтобы играть с телефона по ссылке, включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
